# Python Development

A collection of Python projects built while developing skills in software engineering, backend development, and AI engineering.

## Projects

### 1. Expense Tracker

A command-line application for managing expenses using Python.

**Features**
- Add, view, and delete expenses
- Validate user input
- Store expenses in JSON
- Handle errors using custom exceptions
- Log application events
- Automated tests using pytest

**Technologies:** Python, pytest, Ruff, JSON

[View Expense Tracker](./expense-tracker/README.md)

### 2. Task Management API

A REST API for managing tasks, users, and authentication.

**Planned features**
- Task creation, retrieval, updating, and deletion
- PostgreSQL database integration
- SQLAlchemy ORM
- Request validation with Pydantic
- JWT authentication and role-based authorization
- Automated API tests

**Technologies:** Python, FastAPI, PostgreSQL, SQLAlchemy, Pydantic

*Under development.*
